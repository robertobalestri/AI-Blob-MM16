# AI Blob - Interactive Video Generation System

## 🎬 Interactive Web GUI - LIVE AND RUNNING!

**✅ READY TO USE**: Interactive clip selection interface for collaborative human-AI video generation.

### 🚀 Quick Start - GUI Mode
```bash
# Launch the interactive web interface
./launch_gui.sh
```

**🌐 Access the GUI at: http://localhost:8503**

### ✨ Features
- **🎯 Interactive Clip Selection**: Manually choose from AI-suggested candidate clips (k=10)
- **🎲 "I'm Feeling Lucky"**: Preserve automatic AI selection when desired  
- **📊 Progress Tracking**: Visual progress and narrative context display
- **💾 Session Management**: Save, resume, and export video projects
- **🎨 Modern Interface**: Clean, responsive web-based UI with Italian localization
- **🔗 Seamless Integration**: Works with existing AI pipeline and video generation

## ⚙️ Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Download `lid.176.bin` from https://fasttext.cc/docs/en/language-identification.html and place in root folder
3. Configure environment variables in `.env`
4. Launch GUI: `./launch_gui.sh`
